# Audi Frontend Clone

A responsive frontend clone of the Audi website built using HTML and CSS. This project was created to practice modern web design, responsive layouts, and frontend development skills.

## Features

* Responsive design
* Modern navigation bar
* Hero section
* Vehicle showcase section
* Clean and structured layout
* Mobile-friendly interface

## Technologies Used

* HTML5
* CSS3

## Purpose

This project was developed for educational purposes to improve frontend development skills and gain experience recreating real-world website layouts.
